# TUI: прогресс и AUR; VPN: автовыбор

Изменения по запросам пользователя 2026-10-01.

- Экран команды по умолчанию показывает полосу прогресса и текущую строку. F2 переключает подробный журнал. Ошибка автоматически открывает журнал; его можно снова скрыть.
- Процент берётся из вывода пакетного менеджера или сборщика; без процента/счётчика отображается индикатор активности. Счётчики Ninja не заменяют нумерованные этапы upd.
- AUR получает отдельные фазы: загрузка, проверка и распаковка исходников, сборка, проверка сборки, упаковка и установка. Распознаются английские сообщения и проверенные установленными каталогами переводы makepkg (русский, немецкий, итальянский, китайский).
- Вопросы [Y/n] и [y/N] показывают ✓ Да / ✕ Нет. Стрелки/Tab выбирают, Enter отвечает одним вводом. Ответивший вопрос скрывается; повторный одинаковый вопрос распознаётся отдельно. Ctrl+C продолжает поступать дочернему процессу.
- Управляющая последовательность альтернативного экрана больше не вызывает автоматический выход из TUI. F4 открывает полный терминал и возвращает в TUI; при возврате восстанавливается отрисовка TUI и размер PTY.
- Общая настройка vpn_auto_allow_ru разрешает/исключает российские серверы в группе автовыбора. По умолчанию разрешены, включая чтение старого конфигурационного файла. Переключатель есть в настройках VPN TUI и графическом апплете. Авто в апплете — отдельный пункт; если группа была выключена, действие включает её и выбирает через помощника.
- География определяется по названию узла: флаг, RU/RUS/РФ, Россия/Russia, названия городов. Это не определение физического местоположения по IP. Фильтр применяется к группе Auto, в том числе узлам провайдеров; ручной список и правило «Россия напрямую» сохраняются. Механизм exclude-filter проверен по https://wiki.metacubex.one/en/config/proxy-groups/.

Проверки: 150 lib + 47 CLI + 24 integration + 31 COSMIC + 4 packaging = 256 тестов. Полный gate выполнен последовательно (RUST_TEST_THREADS=1), затем весь CLI проверен после расширения распознавания переводов makepkg. Тесты PTY подтверждают проценты, раскрытие журнала, два одинаковых вопроса с ответами y/n и исчезновение кнопок. Рендеринг проверен в 60×18 и 80×24 на шести языках. Проверены переключение фильтра, сохранение ручных узлов и провайдеров, чтение старого Config, наличие Auto вне короткого списка серверов.

Два ранних параллельных запуска нагрузочного теста helper превысили его пятисекундный бюджет на выдачу 8 МБ. Два изолированных повторения и полный последовательный gate прошли без изменения лимитов ресурсов и дедлайнов. В тестах idle-retry GUI устранена зависимость от реальной блокировки /var/lib/upd: тестовые каталоги теперь изолированы, текущая установка пользователя не затрагивается.

Системные пакеты не устанавливались; текущая работающая операция не перезапускалась. Release CLI и COSMIC сохраняются в dist/. Ограничение совместимости прежнее: GNU GUI собран на текущем хосте, совместимость с glibc Pop!_OS не исправлялась.
