# Остановка работы по поручению пользователя, 2026-10-05

Разработка остановлена по прямому поручению пользователя. Luna прервана; новые этапы
не начинаются. Пользователь отдельно поручил коммит и сводку. Текущая точка — **I03.T04,
частичная реализация**, а не завершённый импорт и не приёмка работающей сети.

## Что завершено кодово

- **I01**: миграция ручного UPD 0.2.7, backup/journal/recover, startup guards,
  проверка старых путей, процессов и занятости; ревью обеих лент симуляции и исправления.
  Подготовлен installation regression driver. Миграция и VPN на действующей системе
  не приняты; отдельные старые прогоны fixtures не подтверждают новые изменения.
- **I02.T01–T05**: strict модель источников, профилей, immutable узлов, сессий и независимых
  осей NET/REGION/STATE/APP; private Store, CAS, долговечная запись/удаление credentials,
  35 подготовленных проверок, examples/contracts и installation driver. Код прошёл
  compile/build проверки. Runtime checks отложены до установки.
- **I03.T01–T03**: pinned capabilities mihomo 1.19.32, bounded UA negotiation/cache,
  actual accepted UA, private artifacts и safe provenance. Старые узлы сохраняют свои
  полные определения, defaults, поколение и pin ядра. 24 проверки подготовлены.

## Что сделано внутри текущего I03.T04

- Private restart settings: явно заданный endpoint, исходный порядок UA и лимиты
  фиксируются до cache reorder и сохраняются только в закрытом Source artifact.
  Endpoint/settings-only refresh сохраняет поколение и immutable Node refs.
- Первая часть native JSON/YAML parser: строгие duplicate keys, byte/depth/entry/node
  limits, protocol-specific plaintext TCP subset VLESS/VMess/SS/HTTP/SOCKS5.
  Неизвестные поля, host controls, неподдержанные sections/providers отвергаются.
- Streaming YAML guard до построения дерева: aliases/anchors/tags/directives/multidoc
  и превышение ресурсов отвергаются; символы в обычных строках остаются данными.
- Parser-to-publication pipeline проверяет соответствие ParsedSource точному принятому
  телу и публикует Source через Store CAS. Native negotiation использует injected fetch:
  HTML/непригодный body допускает bounded retry, unsupported semantics дают terminal отказ.
- По первичному pinned source исправлен `global-client-fingerprint`: ядро его удалило,
  поэтому параметр отклоняется в capabilities/defaults/parser.

Для этой части T04 подготовлены 18 проверок: 9 native, 4 YAML guard, 2 fetch settings,
3 pipeline. Всего I03 — **42 подготовленные проверки, NOT_RUN**. Итоговый
`cargo check --offline --locked --tests` завершился с кодом 0 без предупреждений.
[Логи и hashes остановленного снимка](i03-evidence/stop-check-2026-10-05/summary.json).
Приложение, службы, ядро и provider requests не запускались. Последний бинарник
не пересобран после I03; прошлые build manifests исторические и не подтверждают
совпадение текущих исходников с установленным бинарником.

## Что осталось в строгом порядке

1. **Довести I03.T04**: TLS/REALITY, WS/HTTP/H2/gRPC/XHTTP и оставшиеся native branches
   Trojan/Hysteria2/TUIC/WireGuard; URI/base64; ручной собственный сервер. Валидировать
   принятые вложенные параметры полностью, сохранять их без silent dropping.
   Границы groups/rules/providers фиксировать явно; file resolver нельзя заменить
   произвольным чтением host paths. CLI/UI всё ещё используют legacy singleton;
   новая библиотека пока не является завершённым пользовательским flow.
2. **I03.T05**: закончить regression inventory/installation driver, собрать актуальный CLI,
   проверить COSMIC compile и сохранить matching source/binary manifest. Runtime —
   только при установке собранного бинарника по поручению пользователя.
3. **I04 → I18 по DAG**: core contract/mihomo, Xray/delivery, privileged controller,
   host egress, app network environments, fail-closed/recovery, DNS/IPv6/UDP,
   launcher, группы, brokers/packaging, региональное и приватное окружение,
   качество/выбор, TUI/applet/diagnostics, сквозная приёмка. Включить I15-R и I17-D
   на их месте в очереди. Эти этапы ещё не реализованы в текущей новой архитектуре.
4. При установке — отложенные runtime regressions I01/I02/I03 и дальнейших этапов,
   реальные systemd/package adapters, сохранение настоящего конфига и реальные
   процессные гонки. Никаких утверждений «VPN исправлен» до соответствующей приёмки.

Конкретный HTTP adapter пока не подключён: locked ureq2.12.1 не ограничивает DNS lookup
одним Request timeout. Injected transport должен выполнять deadline/size/redirect contract;
это ограничение нельзя скрыть. Повторные симуляции миграции никому не передавать:
этот вопрос пользователь поручил Sol самостоятельно. Astra не использовалась.
