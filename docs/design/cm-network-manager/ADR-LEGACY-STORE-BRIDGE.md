# ADR: мост legacy Subs и Store (V.01)

Статус: **принят 2026-10-06 — D7: вариант 2** ([решение](DECISIONS-D6-D10-Q01-2026-10-06.md)). `V.02` можно начинать.

Дата: 2026-10-06.

## Что уже есть

Legacy-файл `{etc}/subs.json`, режим каталога как у текущего VPN. Структура `Subs`: поле `active` и `list` записей `Sub` (`src/vpn.rs`). Поле `url` — секрет. Рядом живут `user_agent`, `kind`, `info`, `nodes`, `error`. Store (`src/profiles/store.rs`) — отдельный источник профилей с ревизией и CAS. Сейчас TUI и `cm vpn` читают legacy. Store их не подменяет.

## Варианты для D7

1. Срез V не делать. Legacy остаётся единственным путём пользователя. Store живёт для следующих итераций, импорта `subs.json` нет.
2. Сделать срез V по шагам ниже. На переходный период источник истины для работающего VPN — по-прежнему legacy, пока пользователь явно не переключит флаг (это уже критерий `V.04`, не этот ADR).
3. Отложить срез до закрытия I04 и вернуться к этому ADR без другого текста.

## Как выглядел бы срез, если D7 выберет вариант 2

Это описание объёма, не решение.

- Одноразовый импорт: `cm source import --dry-run` читает `subs.json`, печатает число записей, имена и отказы, не пишет Store и не трогает legacy. Секретный URL в вывод не попадает.
- `apply` после успешного dry-run создаёт источники в Store. Повторный apply той же ревизии legacy не плодит вторую копию: ключ — стабильный id записи `Sub`, а не URL.
- На переходный период работающий VPN продолжает читать legacy. Store — черновик, пока нет отдельного флага использования.
- Откат — удаление импортированных источников этой операции по id, записанным в квитанции. Legacy-файл при откате не переписывается.
- TUI во время перехода показывает прежний экран VPN с legacy. Импортированные источники не становятся активной подпиской сами.

Правка ручного сервера, если до неё дойдёт `V.02`, следует I02: новый Node ID, тот же Source ID; pinned-профили перезакрепляются только после подтверждения.

## Мнение рецензента, не решение

Вариант 2 не ломает текущий VPN, потому что legacy остаётся источником работающего туннеля до отдельного флага. Вариант 1 честнее, если срез V сейчас не нужен: ADR тогда закрывается отказом, а не полуимпортом. Выбирает пользователь.
