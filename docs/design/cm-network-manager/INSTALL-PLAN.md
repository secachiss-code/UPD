# План проверок на установке (X.01, решение D10)

Дата: 2026-10-06. Где: реальный хост разработки (Garuda, btrfs, snapper `root`). Кто: команды с `sudo` выполняет пользователь (в Claude Code — через `! команда`); разбор evidence — Grok/координатор. Сеть и VPN хоста во время окна могут прерываться.

## 0. До начала

1. Закрыть программы, которым нужен стабильный VPN; держать доступ к сети без VPN (на случай отката).
2. Собрать текущий CLI и зафиксировать манифест (`I03.T05.d`): `sh build.sh` → sha256 бинарника в `x-evidence/<дата>/summary.json`.
3. Снимок для отката:
   ```
   sudo snapper -c root create --type single --description "cm X-track before install" --print-number
   ```
   Номер снимка записать в summary. Откат: `sudo snapper -c root rollback <номер>` и перезагрузка (или загрузка снимка из меню grub-btrfs).
4. Сохранить копии: `/var/lib/upd`, `/etc/upd*`, `~/.config/cm` — архивом вне репозитория (содержит секреты подписок, в git не класть).

## 2. Правила окна

- Одна проверка за раз; после каждой — summary без секретов (D8).
- Любая потеря данных или утечка мимо туннеля — стоп, откат снимка, разбор.
- Никаких утверждений «VPN исправлен» без `X.05`.
