# I03.T02: bounded User-Agent negotiation

`src/sources/negotiation.rs` implements a pure policy state machine around injected fetch and body-classifier callbacks. It accepts only an explicitly configured HTTPS endpoint by default; HTTP requires an opt-in. Endpoint and User-Agent values are validated and hidden from `Debug`; endpoint access is exposed only to the trusted fetch callback. No URL guessing, redirect following, converter lookup, parser, persistence, or HTTP client is included.

Preferred and configured candidates retain their order and are deduplicated. A cached winner moves first only when endpoint digest, ordered candidate-set digest, pinned core version, TTL, and current allow-list all match. Only a successful HTTP response rejected as retryably unusable by the classifier advances to the next candidate. Transport, timeout, auth, quota, unavailable endpoint, redirect, server, terminal body, and oversized-body failures stop immediately.

Policy validation bounds attempts, elapsed time, per-request timeout, response size, and cache TTL before fetching. `RequestSpec` communicates a zero redirect limit, remaining total budget, per-request timeout, and byte ceiling. The fetch adapter must enforce its timeout and limit response reads; the state machine checks callback elapsed time before accepting a result but cannot forcibly interrupt an arbitrary blocking callback. Accepted metadata records the actual successful User-Agent, source-body SHA-256, accepted timestamp, request count, and whether the cache hint won. Raw response bytes and generic parsed values are available only through explicit getters and stay redacted in formatting.

`tests/audit_i03_negotiation.rs` contains synthetic callback fixtures for retry order, cache binding/expiry, terminal errors, request and time ceilings, oversize handling, pre-fetch policy rejection, and redacted formatting. Sol review and `cargo check --offline --locked --tests` passed; 10 prepared tests are **NOT_RUN**. [Compile evidence](i03-evidence/negotiation-review-2026-10-04/summary.json). No real source endpoint or network was contacted.

Unix time is sampled once and anchored to the checked monotonic sample immediately afterward. Time spent sampling that clock consumes the total budget, but is not counted again in the accepted timestamp. A dedicated synthetic fixture covers this delay; runtime remains NOT_RUN.
