## Дефекты `.y`, исправленные

1. **P0 — молчаливое отключение проверки сертификата.** Счётчик узлов `tls_verification: Disabled` задавал вызывающий код, а не узлы: узел `Disabled` со счётчиком 0 публиковался без подтверждения, вопреки D2. Теперь счётчик всегда выводится из определений узлов (`with_omissions` и публикация), рассинхрон — `InvalidProvenance`.
2. **P1 — автообновление в пределах подтверждённого не публиковалось.** Валидация требовала digest нового подтверждения, которого при автообновлении нет; граница при каждой публикации перезаписывалась текущими пропусками. Теперь `update_source` для `as_auto_refresh()` сверяет пропуски с `accepted_omissions_bound` **из сохранённого provenance** (снаружи границу подсунуть нельзя) и переносит старую границу; вне границы — `AutoUpdateBlocked`, поколение прежнее.
3. **P1 — пропуски приходили от вызывающего кода.** `create/update_accepted_source_with_omissions` принимали `omissions` параметром — можно опубликовать пустые пропуски, хотя парсер что-то отбросил. Теперь пропуски — поле `ParsedSource` (заполнят `.q`/`.s`), параметр удалён.
4. **P1 — миграция v1→v2 переписывала любые вложенные версии на 2.** Повреждённая или будущая вложенная запись в v1-файле молча становилась «v2». Теперь v1 с вложенной версией ≠ 1 — `UnsupportedSchema`. Тестов миграции не было — добавлены.
5. **P2 — узлы без TLS отмечались `Verified`.** Для Shadowsocks/plain VLESS/WireGuard это читалось бы как «TLS проверен». Добавлен `TlsVerification::NotApplicable` (по умолчанию, миграция v1 ставит его).
