# I15-R.T02.a — покрытие механизмов и поверхностей

Дата: 2026-10-06. Это матрица покрытия механизмов, не измерение. Ни одна ячейка не является probe и не даёт статуса NET, REGION, STATE или APP.

Формулировки — по [Q01](DECISIONS-D6-D10-Q01-2026-10-06.md) и [I15-Q01-FORMULATIONS.md](I15-Q01-FORMULATIONS.md). Разрешено говорить только при свежем evidence конкретной программы: сеть через туннель N; страна выхода по N источникам и времени; часовой пояс и язык согласованы со страной выхода; отдельный профиль данных; адаптер поддержан / частично / не поддержан. Запрещено: полная анонимность, «невозможно отследить», неизвестность аккаунта или оператора, один зелёный статус без осей NET/REGION/STATE/APP.

Пустая ячейка не используется. «неизвестно» значит, что по указанному документу нельзя честно назвать эффект этого механизма на эту поверхность.

| Механизм \ поверхность | UA | Client Hints | workers | Canvas | WebGL | fonts | audio | TLS |
|---|---|---|---|---|---|---|---|---|
| prefs | Firefox: `privacy.resistFingerprinting` описан как защита от снятия отпечатка, без отдельного перечня полей UA в этом тексте. Chromium: отдельный пользовательский pref, который целиком подменяет UA, здесь не установлен. [Firefox](https://support.mozilla.org/en-US/kb/firefox-protection-against-fingerprinting), [MDN UA](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent) | неизвестно. Ближайшее: Client Hints — это заголовки запроса, не ключ about:config. [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Client_hints), [Chrome UA reduction](https://privacysandbox.google.com/protections/user-agent) | неизвестно. Воркер наследует часть агента, но pref, который отдельно меняет воркер, в этих документах не назван. [MDN Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker) | Firefox RFP упоминает защиту отпечатка в целом; точный pref для canvas в процитированной статье не выделен. [Firefox](https://support.mozilla.org/en-US/kb/firefox-protection-against-fingerprinting), [MDN Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) | неизвестно, какой pref меняет рендерер или vendor. [MDN WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API), [Firefox](https://support.mozilla.org/en-US/kb/firefox-protection-against-fingerprinting) | неизвестно. Шрифт — свойство CSS и набор шрифтов ОС, не найденный здесь pref. [MDN font](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font) | неизвестно. [MDN Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) | неизвестно. Политика TLS движка не сводится к одному пользовательскому pref в этих страницах. [MDN TLS](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security) |
| расширения | Расширение может видеть и менять заголовки запроса, включая User-Agent, через webRequest. Это не обещание, что страница перестанет читать `navigator.userAgent`. [Chrome webRequest](https://developer.chrome.com/docs/extensions/reference/api/webRequest), [Firefox webRequest](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest), [MDN UA](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent) | неизвестно, перехватывает ли обычное расширение все Client Hints после UA reduction. Заголовки запроса описаны отдельно. [MDN Client Hints](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Client_hints), [Chrome](https://privacysandbox.google.com/protections/user-agent) | неизвестно. Воркер не является документом расширения. [MDN Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker) | неизвестно. Canvas API не даёт расширению общего перехвата пикселей страницы. [MDN Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) | неизвестно. [MDN WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) | неизвестно. [MDN font](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font) | неизвестно. [MDN Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) | неизвестно. TLS-рукопожатие не является webRequest-телом. [MDN TLS](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security) |
| CDP | `Emulation.setUserAgentOverride` задаёт UA для целей протокола. Это не измерение страны выхода и не скрытие аккаунта. [CDP Emulation.setUserAgentOverride](https://chromedevtools.github.io/devtools-protocol/tot/Emulation/#method-setUserAgentOverride), [MDN UA](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent) | Тот же метод принимает `userAgentMetadata` (Client Hints metadata). Полнота против UA reduction здесь не измерялась. [CDP](https://chromedevtools.github.io/devtools-protocol/tot/Emulation/#method-setUserAgentOverride), [Chrome](https://privacysandbox.google.com/protections/user-agent) | неизвестно, наследует ли уже созданный Worker override без нового документа. [MDN Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker) | неизвестно. В перечисленных страницах CDP нет подтверждённого перехвата `toDataURL`. [MDN Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) | неизвестно. [MDN WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) | неизвестно. [MDN font](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font) | неизвестно. [MDN Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) | неизвестно. CDP не заменяет стек TLS. [MDN TLS](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security) |
| патчи движка | Chrome уменьшает UA и переносит детали в Client Hints. Firefox RFP меняет поведение движка, а не только заголовок. [Chrome](https://privacysandbox.google.com/protections/user-agent), [Firefox](https://support.mozilla.org/en-US/kb/firefox-protection-against-fingerprinting), [MDN UA](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent) | UA reduction — изменение движка Chromium: подсказки отдаются по политике, не «выключены prefs». [Chrome](https://privacysandbox.google.com/protections/user-agent), [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Client_hints) | Воркер — отдельный глобальный контекст того же агента. Патч, который расходится между окном и воркером, в этих документах не обещан. [MDN Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker) | Canvas читает пиксели. Движок может шуметь или отказывать (Firefox RFP описывает защиту отпечатка, без цифр в этой матрице). [MDN Canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API), [Firefox](https://support.mozilla.org/en-US/kb/firefox-protection-against-fingerprinting) | WebGL отдаёт параметры рендерера. Что именно режет конкретный патч — неизвестно без версии движка. [MDN WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) | Набор шрифтов и `font` — поверхность движка и ОС. Отдельный патч CM здесь не выбран. [MDN font](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font) | `AnalyserNode` и частота дискретизации — поверхность Web Audio. Эффект патча — неизвестно. [MDN Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) | Стек TLS принадлежит движку (наборы, расширения, порядок). Это не страна выхода и не неизвестность оператора. [MDN TLS](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security) |

Следствие для I15-R дальше: обещание пользователю строится только из четырёх осей и свежего evidence. Эта таблица говорит, где механизм вообще описан, и не подменяет probe.
