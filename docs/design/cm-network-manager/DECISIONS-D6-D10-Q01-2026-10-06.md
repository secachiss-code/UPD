## Q01: что CM вправе показывать пользователю

Разрешено (каждое — только при свежем evidence соответствующей оси):

- «Сеть приложения идёт через туннель N» — NET, проверено probe для этой программы.
- «Страна выхода: X (по N источникам, проверено T назад)» — REGION.
- «Часовой пояс и язык приложения согласованы со страной выхода» — REGION.
- «Отдельный профиль данных приложения» — STATE.
- «Адаптер приложения: поддержан / частично / не поддержан» — APP, с перечнем свойств.

Запрещено в интерфейсе и документации:

- «Полная анонимность», «вас невозможно отследить», «анонимизация выполнена».
- Любое обещание о неизвестности аккаунта, оператора сети или всех поверхностей отпечатка.
- Зелёный общий статус без разбивки по осям NET/REGION/STATE/APP.

Желание полной анонимизации сохраняется как цель исследования I15-R, а не как свойство продукта.
