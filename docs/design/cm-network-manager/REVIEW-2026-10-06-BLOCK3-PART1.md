# Ревью блока 3, часть 1: H.12 и I03.T05.b, 2026-10-06

Исполнитель — Grok 4.7, ревью и доводка — координатор. Очередь: [GROK-QUEUE §Блок 3](GROK-QUEUE-2026-10-06.md).

| ID | Итог | Что исправлено при ревью |
|---|---|---|
| `H.12` PTY без CLOEXEC | принято | slave PTY открывался по пути `/dev/pts/N`; при нескольких экземплярах devpts (контейнер, private `/dev`, другое mount namespace) это чужой или несуществующий терминал. Теперь `ioctl(TIOCGPTPEER)` от самого master, путь — только запасной вариант для ядер до 4.13 |
| `I03.T05.b` отказы источника | принято | заголовок `subscription-userinfo` длиннее 512 байт блокировал весь импорт как «квота исчерпана». Теперь такой заголовок считается неизвестным и игнорируется; тест `odd_subscription_userinfo_does_not_block_refresh` (длинный, без `=`, нечисловой) |

Найдено попутно и исправлено:

- **`/tmp` переполнялся временными сборками координатора** (4.9 ГБ в tmpfs) — удалены; сборки координатора и Grok теперь в `~/.cache/cm-*-target`.
- **Тесты zypper в `src/backend.rs` оставляли каталоги в `/tmp`** (по 26 штук каждого вида) по предсказуемому пути `cm-zypper-*-PID`, с исполняемым скриптом первым в `PATH`. Переведены на `TempDirGuard` (уникальный приватный каталог, удаляется после теста).

Процесс: Grok сдал без прогона `tests/check_audit.sh` (только `cargo test`), что требует правило блока. Gate после доводки: **EXIT=0, 456 passed, 0 failed** (включая COSMIC, rustfmt и clippy новых модулей). Installation runtime: NOT_RUN.
