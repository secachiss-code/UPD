# Предложение: evidence в git (H.08)

Статус: **предложение, не политика**. D8 не решён. Новые сырые логи по этому тексту не выносятся и не удаляются, пока решение не записано.

Дата: 2026-10-06.

## Что предлагается

В git остаётся только `summary.json`: команда, счётчики, ревизия, sha256 lock-файла, короткий итог. Сырой stdout/stderr сборки и тестов в репозиторий не кладётся. Его место — каталог вне дерева (например кэш исполнителя) либо архив релиза, если прогон нужно приложить к версии.

Уже лежащие в git логи это предложение не удаляет и не переписывает. Правило, если его примут, действует на evidence после даты решения.

## Что не предлагается

- Не хранить секреты, URL подписок и тела конфигов ни в summary, ни в сыром логе.
- Не считать summary заменой ревью: координатор по-прежнему смотрит diff и прогон.

Так уже устроены последние summary (`h12-evidence`, `i03-evidence`). Имеет смысл закрепить это как D8, а не копить новые полные логи. Решает пользователь.
