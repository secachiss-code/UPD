## Сделано координатором

- `.s` — `parser/list.rs`: списки URI и base64 (два слоя), пропуски по D3 с классом и номером строки, без текста строки; ноль узлов — отказ.
- `.t` — `detect_body`, `parse_source`, `pipeline::negotiate_source`: HTML/заглушка → повтор UA, пустое/большое/третий слой/неподдержанная семантика → terminal. Все 9 fixtures Grok.
- `.u` — `sources/manual.rs`: секрет только из stdin или файла, `SecretInArgv` для любого секрета и URI в argv; правка — новое поколение того же Source.
- `.v` — сквозной тест: два источника, профиль на каждом, обновление одного не трогает другой, удаление используемого источника отклоняется до отвязки.
- `.w` — корпус из 12 узлов (каждое поддержанное сочетание) принимается парсером; проверка ядром через `CM_TEST_MIHOMO`, без бинарника — SKIPPED.
- `.x` — [I03-PARSER-FINAL](I03-PARSER-FINAL.md). Закрытие T04 ждёт `H.05.b` (saphyr).

## Конфликт контракта

Fixture Grok `edit-server` и текст `.u` требуют «тот же Node ID после правки сервера». Модель I02: Node ID выдаётся один раз, узел неизменяем и принадлежит поколению источника. Реализовано по модели: Source ID сохраняется, поколение +1, Node ID новый. Изменить можно только решением пользователя с пересмотром I02.
