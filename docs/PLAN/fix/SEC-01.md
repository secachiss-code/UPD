## Проверка смежных участков

src/vpn.rs:168–187, 367–391, 429–445; src/common.rs:354–360; Cargo.lock: ureq 2.12.1. В ureq/src/error.rs:210–238 Display печатает URL, включая redirect origin.

## Правка

В vpn::get на строках 170–185 заменить форматирование сырого ureq::Error на отдельный классификатор: для Status выводить только HTTP-код и тип попытки; для Transport — безопасную категорию/сообщение без URL и вложенного source. В update_subs сохранять только безопасный текст; перед публикацией из publish_state не пропускать старые строки ошибок с исходными URL (миграция/очистка при чтении). Не логировать сырой URL в add_sub.

## Готово, когда

HTTP 401 и DNS-ошибка для URL с userinfo, token path/query и redirect показывают код/категорию; секрет отсутствует в stdout, журнале, subs.error и публичном vpn.json.

## Ограничение / риск

Санитизация лишь одной точки публикации не устраняет утечку в журнале.
