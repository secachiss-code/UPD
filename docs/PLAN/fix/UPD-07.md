# UPD-07 — Считать невозможность запуска pacman ошибкой проверки?

**Оценка:** подтверждено для кода -1. **Источник:** дополнительная перепроверка смежного кода; в `docs/BUGS.md` записи нет.

**Перед началом:** закрыты [UPD-01](../fix/UPD-01.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/common.rs:403–408: out возвращает code=-1 при spawn error/сигнале; src/backend.rs:268–278: Pacman::updates считает ошибкой только code>1, поэтому -1 проходит как Ok(empty).

## Правка

В Pacman::updates после out проверить допустимые коды 0 и 1 по семантике pacman -Qu; любое другое значение, включая -1, вернуть Err. Зафиксировать stderr/spawn failure в сообщении без ложного пустого списка. Вызов gather и cmd_update используют существующие правила UPD-01 для fatal ошибки.

## Готово, когда

Коды 0/1 обрабатываются согласно реальной семантике pacman; -1 и неожиданный код возвращают Err и не превращаются в «система обновлена».

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
