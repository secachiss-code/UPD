# NET-04 — Подтверждать смену сети только после применения зеркал?

**Оценка:** подтверждено. **Источник:** дополнительная перепроверка смежного кода; в `docs/BUGS.md` записи нет.

**Перед началом:** закрыты [NET-02](../fix/NET-02.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/mirrors.rs:235–262 записывает best/fingerprint/checked до apply_mirrors; apply_mirrors:282–304 возвращает false при ошибке записи; check_mirrors:261 игнорирует результат; handle_network:332–335 затем считает id уже обработанным.

## Правка

Разделить измеренные лучшие зеркала и подтверждённое применение: обновлять fingerprint/last_applied лишь после успешного b.apply_mirrors либо хранить pending_apply и повторять его при следующем net/auto. Возвращать результат применения через check_mirrors/handle_network; не писать событие «Лучшее зеркало» как применённое при отказе. Сохранить результаты замеров для диагностики.

## Готово, когда

При ошибке записи mirrorlist состояние сохраняет pending/error, следующий net повторяет применение; при успехе id отмечается применённым и повтор не нужен.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
