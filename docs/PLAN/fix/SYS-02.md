# SYS-02 — Искать модули текущего ядра в обеих раскладках?

**Оценка:** подтверждено для систем без merged /usr; среда условная. **Источник:** `docs/BUGS.md`, запись `SYS-02`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/common.rs:708–720: используются только /usr/lib/modules, даже если /lib/modules существует отдельно.

## Правка

В reboot_needed выбрать существующий каталог модулей по /usr/lib/modules и /lib/modules (не дублировать один symlink target); для running release и поиска новых modules.dep использовать согласованный набор. Отсутствие одного пути при наличии второго не считать потерей running kernel.

## Готово, когда

При единственном /lib/modules/<running> reboot_needed=false, если нет прочих причин; новое ядро/маркер по-прежнему дают true.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
