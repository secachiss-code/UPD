# UPD-06 — Охватить пользовательские Flatpak установки?

**Оценка:** подтверждено для root-запусков и per-user installations. **Источник:** `docs/BUGS.md`, запись `UPD-06`.

**Перед началом:** закрыты [UPD-04A](../fix/UPD-04A.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/main.rs:167–177, 237; src/extras.rs:8–27. Есть invoking_user() в src/common.rs:453–455, но Flatpak его не использует.

## Правка

Разделить запросы Flatpak на системную установку (--system) и установку invoking_user() (--user от имени пользователя через runuser/sudo, с корректным HOME/XDG_RUNTIME_DIR). Объединять результаты с указанием scope; prefetch/upgrade направлять в тот же scope. Для auto без вызывающего пользователя задать явную политику охвата настроенных пользователей либо документировать scope и не заявлять полный охват.

## Готово, когда

В fixture с system и user установками обе показаны и обновляются в своих областях; root не создаёт отдельную user установку.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
