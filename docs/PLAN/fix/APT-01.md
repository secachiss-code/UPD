## Проверка смежных участков

src/backend.rs:531–540 сохраняет исходный текст, 557–563 целиком восстанавливает старую копию без сравнения текущего файла.

## Правка

В Apt::remove_mirrors хранить слепок применённой версии/хэш при apply; при restore удалять только собственную подстановку mirror+file и сохранять пользовательские строки, либо при конфликте отказаться от перезаписи и сообщить путь для ручного merge. Не удалять backup при конфликте/ошибке. Учитывать source files, изменённые после apply.

## Готово, когда

Добавленная администратором stanza после apply остаётся после remove; неизменённый файл восстанавливается точно; конфликт отмечается без потери данных.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
