## Проверка смежных участков

src/main.rs:1072–1083: запрет действует только когда PKG_BIN существует и exe != PKG_BIN.

## Правка

В cmd_install при !pkg и наличии пакетного PKG_BIN отказывать независимо от совпадения exe; служебный --package разрешать только при подтверждённом пакетном контексте/установочном скрипте. Проверить симлинки через canonicalize и layout. Не копировать пакетный бинарник в LOCAL_BIN.

## Готово, когда

Запуск /usr/bin/upd install при пакетной установке даёт отказ до записи /usr/local/bin и /etc units; package postinstall продолжает работать.
