## Проверка смежных участков

src/vpn.rs:285–291 удаляет оба старых расширения до write_private; delete_sub:347–355 удаляет профиль до save_subs.

## Правка

В fetch_sub сначала записать новый профиль во временный файл и проверить синтаксис/синхронизацию, затем атомарно заменить нужный профиль, после успешного сохранения subs.json удалить старое расширение. В delete_sub сначала сохранить список без подписки, затем удалить профиль; при ошибке удаления оставить безопасный orphan для cleanup. Согласовать с DATA-01 lock и не потерять активный профиль при ошибке JSON.

## Готово, когда

Инъекция ENOSPC на каждом write сохраняет прежний профиль и прежнюю запись подписки; успешное удаление не оставляет активной ссылки на удалённый профиль.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
