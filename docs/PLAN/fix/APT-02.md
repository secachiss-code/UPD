# APT-02 — Делать переход APT на mirror+file восстановимым?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `APT-02`.

**Перед началом:** закрыты [SEC-04A](../fix/SEC-04A.md), [SEC-04B](../fix/SEC-04B.md), [SEC-04C](../fix/SEC-04C.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/backend.rs:531–555: backup/source файлы меняются по очереди, список зеркал пишется в конце, rollback нет.

## Правка

В Apt::apply_mirrors сначала подготовить и fsync новый APT_LIST, затем резервные копии/метаданные, затем атомарные замены source-файлов; вести журнал транзакции для нескольких файлов. На любой ошибке откатить уже заменённые файлы и список до прежнего состояния, сохраняя backup для восстановления. Не помечать changed=true до commit. В remove_mirrors применять симметричную безопасную последовательность.

## Готово, когда

Инъекция ошибки после каждого шага оставляет либо старую конфигурацию, либо полностью рабочую новую; apt source никогда не ссылается на отсутствующий список после завершения.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
