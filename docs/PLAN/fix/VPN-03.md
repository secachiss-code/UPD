# VPN-03 — Сообщать об ошибке перезапуска после обновления ядра?

**Оценка:** подтверждено. **Источник:** дополнительная перепроверка смежного кода; в `docs/BUGS.md` записи нет.

**Перед началом:** закрыты [SEC-02](../fix/SEC-02.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/main.rs:638–646: CLI core update/reinstall игнорирует vpn::restart Err и возвращает успех core_install; src/vpn.rs:1108–1117: maintain сохраняет событие об обновлении, затем игнорирует restart Err.

## Правка

После успешного core_install отдельно обработать restart Result в CLI и maintain; если служба активна и restart не удался, дать ненулевой код CLI/запись ошибки состояния и не утверждать, что новое ядро активно. Отложить flclash_applied/event подтверждения до успешного restart либо явно обозначить «на диске обновлено, запуск не удался». Сохранить путь восстановления предыдущего бинарника при необходимости.

## Готово, когда

При успешной замене и неудачном restart CLI возвращает ошибку, фоновое состояние показывает проблему; при успешном restart версия активного процесса соответствует установленной.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
