# PARSE-01 — Декодировать filename* без паники?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `PARSE-01`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/vpn.rs:124–141: pct_decode итерирует байты, но берёт срез &s[i+1..i+3]; индекс может попасть внутрь UTF-8 code point.

## Правка

В pct_decode разбирать пары hex непосредственно из b[i+1], b[i+2] без строкового среза; при неправильном % копировать исходные байты и завершать String::from_utf8_lossy. Ограничить размер заголовка/имени, затем применять очистку имени из SEC-05.

## Готово, когда

Заголовок с буквальной кириллицей и повреждённым % не вызывает panic; корректный %D0... декодируется; ошибочный % сохраняется/безопасно заменяется.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
