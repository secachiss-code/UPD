# VPN-02 — Находить IPv6 listener FlClash?

**Оценка:** подтверждено для tcp6-only listener. **Источник:** `docs/BUGS.md`, запись `VPN-02`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/vpn.rs:204–213 читает только /proc/net/tcp и IPv4 адреса 127.0.0.1/0.0.0.0.

## Правка

В flclash_ports добавить чтение /proc/net/tcp6 с разбором inode, LISTEN и локального IPv6 loopback/unspecified; не включать удалённые сокеты и не дублировать порт. В get прокси-адрес должен соответствовать доступности IPv6 listener: использовать [::1] для tcp6-only, а не всегда 127.0.0.1.

## Готово, когда

FlClashCore с tcp6 [::1]:port используется как прокси; IPv4 путь работает; чужой процесс/remote socket не попадает в список.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
