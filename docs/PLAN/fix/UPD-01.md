# UPD-01 — Возвращать ошибку при неудачной проверке системных пакетов?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `UPD-01`.

**Перед началом:** закрыты [UPD-05](../fix/UPD-05.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/mirrors.rs:398–402; src/main.rs:255–272: cmd_update распознаёт только текст ошибки refresh.

## Правка

В cmd_update сразу после gather проверять типизированный результат проверки пакетов, а не сравнивать st.error с одной русской строкой. Непустой fatal error должен прерывать до сообщения «Система уже обновлена» и возвращать 1. Если st.error одновременно содержит предупреждение о месте, сохранить отдельную классификацию; не разрешать ложный success при ошибке updates().

## Готово, когда

При Err из Backend::updates() и пустых дополнительных списках нет сообщения об актуальной системе, exit=1; при Ok(empty) оно есть, exit=0.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
