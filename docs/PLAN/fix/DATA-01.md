# DATA-01 — Сериализовать изменения списка VPN подписок?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `DATA-01`.

**Перед началом:** закрыты [DATA-02](../fix/DATA-02.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/main.rs:181–205 lock используется update/auto, но cmd_vpn:535–573 нет; src/vpn.rs:326–391 выполняет read-modify-write без блокировки.

## Правка

Ввести отдельную блокировку для subs.json либо общую с чётким порядком захвата; оборачивать полную транзакцию add/delete/use/update_subs, включая чтение и сохранение. Не брать один lock повторно из auto, чтобы избежать deadlock; при auto удерживать/передавать guard. Сериализовать также запись профиля с соответствующим изменением JSON.

## Готово, когда

Два конкурентных add сохраняют обе подписки; delete параллельно auto не возвращает запись; второй процесс ждёт или получает явную busy ошибку.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
