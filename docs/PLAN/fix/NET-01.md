# NET-01 — Учитывать IPv6 default route в отпечатке сети?

**Оценка:** подтверждено для IPv6-only route. **Источник:** `docs/BUGS.md`, запись `NET-01`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/common.rs:589–615 читает только /proc/net/route; src/mirrors.rs:323–333 пропускает обработку при online=false.

## Правка

В common::fingerprint добавить разбор /proc/net/ipv6_route с выбором default route по metric и состоянию интерфейса; включить семейство адресов, gateway и интерфейс в raw/id/label. Не считать наличие TUN само по себе доказательством маршрута в интернет; сохранить IPv4 при dual-stack. При смене только IPv6 gateway должен меняться id.

## Готово, когда

IPv6-only default route даёт online=true и стабильный id; изменение gateway меняет id и запускает обработку сети; отсутствие маршрута даёт offline.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
