# UPD-02B — Учитывать ошибку установки прошивки в результате update?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `UPD-02`.

**Перед началом:** закрыты [UPD-04B](../fix/UPD-04B.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/main.rs:331–347: updates.json очищается до firmware_upgrade, его результат игнорируется.

## Правка

В cmd_update при согласии пользователя выполнить firmware_upgrade с обработкой Result; ошибка должна менять итоговый код и оставлять список прошивок в состоянии. При отказе пользователя от установки прошивок не отмечать их установленными. Перенести финальное сохранение/итоговое сообщение после шага firmware.

## Готово, когда

Ошибка fwupdmgr update даёт ненулевой код и сохранённый список; сознательный отказ оставляет список без ложного сообщения об установке; успех очищает только установленное.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
