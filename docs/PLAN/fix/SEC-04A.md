# SEC-04A — Сделать APT backup закрытым?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `SEC-04`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/backend.rs:531–541, 557; src/common.rs:354–360: apt-backup.json пишется 0644 в каталоге 0755.

## Правка

Заменить save_json("apt-backup.json", &backup) на отдельную запись с 0600 в закрытом каталоге либо отдельный private_state_json; при уже существующем backup сделать миграцию прав до чтения/перезаписи. Сохранить атомарность записи. В remove_mirrors читать из того же места. Не менять общий режим updates.json/vpn.json ради APT.

## Готово, когда

Секрет из исходного APT-файла после apply доступен только root в backup; restore читает сохранённый текст.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
