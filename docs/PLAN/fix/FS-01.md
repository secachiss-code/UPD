# FS-01 — Выделять закрытое временное место для зеркал?

**Оценка:** условно: путь подтверждён, symlink-эксплуатация не проверена. **Источник:** `docs/BUGS.md`, запись `FS-01`.

**Перед началом:** закрыты —. Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/backend.rs:86–88, 186–200. Внешние rate-mirrors/reflector пишут по предсказуемому /tmp/upd-mirrors.<PID>; защита ядра и поведение утилит не исследованы.

## Правка

Заменить tmp_path("mirrors") в Pacman::discover на приватный временный каталог со случайным именем и режимом 0700 (например tempfile::tempdir в контролируемом каталоге), а файл --save разместить внутри. Каталог удерживать до read_to_string и удалять через RAII. Ошибку создания/чтения обрабатывать как ошибку автопоиска, сохраняя fallback. Не полагаться на один PID и проверку symlink после запуска.

## Готово, когда

Предсозданный атакующим /tmp/upd-mirrors.<PID> не используется; путь вывода находится внутри каталога 0700, cleanup происходит и при ошибке утилиты.

## Ограничение / риск

Проверить интерфейсы обеих утилит на поддерживаемых версиях; эксплуатацию root-записи отдельно не заявлять.
