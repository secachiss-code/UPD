# SEC-04B — Защитить сохранённый APT URI?

**Оценка:** подтверждено. **Источник:** `docs/BUGS.md`, запись `SEC-04`.

**Перед началом:** закрыты [SEC-04A](../fix/SEC-04A.md). Открыть только этот detail; перепроверить строковые якоря.

## Проверка смежных участков

src/backend.rs:528–554: fs::write(apt-original-uri) наследует umask процесса; URI может содержать credentials.

## Правка

Для apt-original-uri в Apt::apply_mirrors заменить fs::write на atomic_write(..., 0o600) в закрытом каталоге; проверять и возвращать ошибку записи, не игнорировать её. При миграции уже созданного файла ограничить права. Согласовать путь/очистку с remove_mirrors.

## Готово, когда

URI с credentials не читается непривилегированным пользователем и не теряется при успешном apply.

## Ограничение / риск

Сохранить поведение соседних веток, особенно обработку отказа и уже записанное состояние.
