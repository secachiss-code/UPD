# Настройки upd 0.2.2

Главный конфигурационный файл: `/etc/upd.conf`. При первом запуске от root он создаётся со значениями по умолчанию. Его можно редактировать вручную или изменять часть параметров через TUI. Булевы значения задаются числами: `1` — включено, `0` — выключено. Неизвестные ключи и строки без `=` игнорируются; строки, начинающиеся с `#`, являются комментариями.

Список пользовательских зеркал задаётся повторяющимися строками `mirror = URL`. URL добавляются к автоматическому поиску и закреплённым зеркалам, а не заменяют их. Если конфигурационный файл уже существует, но строк `mirror` нет, предпочтительных зеркал не будет.

## Обновление и зеркала

| Ключ | По умолчанию | Значение |
|---|---:|---|
| `keep` | `3` | Сколько лучших зеркал закреплять в начале списка. При чтении минимум `1`. |
| `timeout` | `10` | Таймаут одного замера зеркала, секунды. При чтении минимум `2`. |
| `extra_from_list` | `8` | Сколько зеркал из текущего системного списка дополнительно замерять. При чтении минимум `0`. |
| `rescan_count` | `15` | Сколько результатов брать из автопоиска. При чтении минимум `3`. |
| `retries` | `5` | Число попыток предзагрузки пакетов. При чтении минимум `1`. |
| `mirror_max_age_h` | `12` | Возраст замера в часах, после которого зеркала проверяются снова. |
| `network_memory_days` | `3` | Сколько дней использовать сохранённые лучшие зеркала знакомой сети. |
| `max_lag_h` | `3` | Максимальное отставание зеркала от самого свежего, часы. При чтении минимум `1`. |
| `parallel` | `4` | Одновременные замеры зеркал без обнаруженного VPN/TUN. При чтении минимум `1`. |
| `parallel_vpn` | `2` | Одновременные замеры при обнаруженном VPN/TUN. При чтении минимум `1`. |
| `mirror` | зависит от менеджера при первом создании файла | Предпочтительное зеркало; можно задать несколько строк `mirror = URL`. |

`mirror_max_age_h` и `network_memory_days` загружаются как целые числа без ограничения диапазона. Для обычной работы задавайте положительные значения.

## Предзагрузка и дополнительные компоненты

| Ключ | По умолчанию | Значение |
|---|---:|---|
| `prefetch` | `1` | Заранее скачивать системные пакеты в фоне. |
| `prefetch_on_battery` | `0` | Разрешить фоновую загрузку от батареи. При `0` проверка остаётся, загрузка откладывается. |
| `prefetch_on_metered` | `0` | Разрешить фоновую задачу в лимитной сети. При `0` она целиком пропускается. |
| `min_free_gb` | `2` | Требуемый запас свободного места после загрузки, ГБ. При чтении минимум `0`. |
| `flatpak` | `1` | Проверять, предзагружать и устанавливать обновления Flatpak, если команда доступна. |
| `aur` | `1` | Проверять и обновлять AUR через `paru`/`yay` при ручном обновлении от пользователя. |
| `firmware` | `1` | Проверять прошивки через fwupd и предлагать установку после обновления системы. |
| `news` | `1` | Проверять новости Arch перед обновлением на Arch и производных, кроме Manjaro. |
| `snapshot` | `1` | Делать снапшот перед обновлением, если пакетный менеджер не делает это сам. |

## VPN

| Ключ | По умолчанию | Значение |
|---|---:|---|
| `vpn_tun` | `1` | Включить TUN для всего системного трафика. При `0` остаётся локальный прокси. |
| `vpn_autostart` | `1` | Включать службу mihomo при загрузке. Настройка применяется при запуске VPN или установке `upd` с уже добавленной подпиской. |
| `vpn_direct_ru` | `1` | Направлять домены и IP России напрямую по правилам и геофайлам. |
| `vpn_direct_lan` | `1` | Направлять частные сети напрямую. |
| `vpn_auto_select` | `1` | Создать группу `⚡ Авто`, выбирающую сервер по задержке. |
| `vpn_dns` | `1` | Включить собственный DNS mihomo с fake-IP и DNS-over-HTTPS. При `0` используется DNS из профиля подписки. |
| `vpn_ipv6` | `0` | Включить IPv6 в конфигурации mihomo и DNS. |
| `vpn_allow_lan` | `0` | Разрешить подключения к прокси с других устройств в LAN. |
| `vpn_port` | `7897` | Порт локального HTTP/SOCKS-прокси. Интерфейс TUI принимает `1024`–`65535`, кроме `9097`, занятого API mihomo. При ручной настройке не используйте порт `9097`. |
| `vpn_mode` | `0` | Маршрутизация: `0` — `rule`, `1` — `global`, `2` — `direct`. |
| `vpn_sub_update_h` | `12` | Период обновления подписок в часах, если провайдер не указал свой. При чтении минимум `1`. |
| `vpn_core_check_h` | `24` | Период проверки релизов ядра VPN в часах. При чтении минимум `1`. |

При загрузке конфигурации `vpn_port` ограничивается диапазоном `1`–`65535`, а `vpn_mode` — диапазоном `0`–`2`. Для `vpn_port` используйте значение, допустимое для TUI, и не выбирайте порт контроллера `9097`.

Пользовательские правила хранятся отдельно в `/etc/upd/vpn/rules.txt` и идут раньше правил локальной сети, России и подписки. Секретный URL подписки и ключ API находятся в `/etc/upd/vpn`; не помещайте их в общедоступные файлы и резервные копии без соответствующей защиты.

## Где меняются параметры

- `/etc/upd.conf` — зеркала, предзагрузка, интеграции и основные параметры VPN.
- `upd` → экран «Зеркала» — количество закрепляемых зеркал и список предпочтительных адресов.
- `upd` → экран VPN → «Настройки» — режим, маршрутизация, DNS, автозапуск, авто-выбор, LAN, порт и интервалы.
- `upd vpn rules` — открыть редактор правил VPN.

Пример короткого фрагмента:

```ini
prefetch = 1
prefetch_on_battery = 0
min_free_gb = 4
keep = 3
mirror = https://mirror.example.org/$repo/os/$arch
vpn_mode = 0
vpn_tun = 1
```
