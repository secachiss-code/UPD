# upd

Обновление Linux одной командой: автоподбор зеркал, предзагрузка в фоне, снапшоты, Flatpak, AUR,
прошивки, новости Arch и перезапуск служб. Один статический бинарник (Rust, musl, ~3 МБ) без зависимостей.

## Установка

```sh
sudo ./upd-linux-amd64 install
upd                                # интерфейс
```

`install` копирует себя в `/usr/local/bin/upd`, создаёт `/etc/upd.conf`, ставит службы, подбирает зеркала
и запускает первую проверку. `sudo upd uninstall` всё убирает и возвращает зеркала как было.

## Обновление (`upd update`, пункт 1 в меню)

1. **Зеркала.** Сменилась сеть — переподбор, иначе перепроверка, если замер старше `mirror_max_age_h`.
2. **Проверка.** Пакеты (через временную базу, системная не трогается), Flatpak, AUR, прошивки, **новости Arch**
   с прошлого обновления (подтверждение, что прочитал), **место на диске** (размер загрузки + `min_free_gb`).
3. **Загрузка** с повторами; на второй неудаче — переподбор зеркал.
4. **Снапшот.** Если есть snap-pac — он сам; иначе snapper (pre/post) или timeshift.
5. **Установка.** `garuda-update` (без перезаписи зеркал, AUR через `UPDATE_AUR`) или `pacman -Syu` / apt / dnf / zypper,
   затем AUR (paru/yay от имени пользователя) и Flatpak.
6. **После.** Прошивки (по подтверждению), **службы со старыми библиотеками** — перезапуск, нужна ли перезагрузка, `.pacnew`.

## Подбор зеркал

- **Отпечаток сети**: шлюз, его MAC, поднятые VPN/TUN (только `/proc` и `/sys`). Новая сеть — поиск зеркал рядом
  (rate-mirrors / reflector / archlinux.org) и замер. Знакомая — сразу её зеркала, потом перепроверка.
- **Замер** — реальная загрузка 3 МБ. Медленное, но живое зеркало засчитывается по тому, что успело прийти.
- **Свежесть** — `lastsync` (Arch) / `Date` в `InRelease` (apt): отставшие больше `max_lag_h` не берутся.
- **Сглаживание** — скорость усредняется по истории замеров в каждой сети; быстрые отказы (обрыв) и ранее
  рабочие зеркала замеряются повторно.
- **VPN/прокси** — меньше параллельных замеров (`parallel_vpn`); если зеркало из конфига не отвечает через VPN,
  появляется подсказка добавить его в правила DIRECT.
- Перезаписали список (rate-mirrors, garuda-update) — `upd-mirrors.path` мгновенно возвращает закреплённые.

## Фон и ноутбук

`upd-auto.timer` (раз в 6 ч): смена сети, замер зеркал, проверка, предзагрузка.
**От батареи** — только проверка, без загрузки (`prefetch_on_battery`). **Лимитная сеть** (точка доступа) —
ничего не качает и не замеряет (`prefetch_on_metered`). `upd-net.timer` + NetworkManager — смена сети.
`upd-notify.timer` — уведомления: обновления, новости Arch, прошивки, перезагрузка, смена зеркал.

## Поддержка

| | Arch / Garuda / EndeavourOS / CachyOS | Debian / Ubuntu | Fedora / RHEL | openSUSE |
|---|---|---|---|---|
| Обновление, предзагрузка, место на диске | ✓ | ✓ | ✓ | ✓ |
| Автоподбор зеркал | ✓ | ✓ (`mirror+file:`) | сам дистрибутив (metalink) | сам (MirrorCache) |
| Новости перед обновлением | ✓ | — | — | — |
| Снапшоты, Flatpak, прошивки, перезапуск служб | ✓ | ✓ | ✓ | ✓ |

## Команды

```
upd                 интерфейс
upd update          обновить всё
upd check           проверить и скачать заранее
upd list | status   что доступно / состояние
upd news [--all]    новости Arch
upd mirrors [status|check|rescan|apply|add URL|del URL]
upd snapshots       снапшоты и как откатиться
upd restart         перезапустить службы со старыми библиотеками
upd clean | merge   очистка / слияние .pacnew
upd install | uninstall
```

Отладка замеров: `UPD_DEBUG=1 upd mirrors check`.

## Сборка

Rust + цель `x86_64-unknown-linux-musl` (`rustup target add x86_64-unknown-linux-musl`), gcc: `./build.sh`.
